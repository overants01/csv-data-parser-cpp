# cpp-expense-tracker 📊

โปรแกรมบันทึกรายรับ-รายจ่ายผ่านหน้าจอคอนโซล พัฒนาด้วยภาษา **C++17** โดยจำลองการทำงานของระบบฐานข้อมูลภายในเครื่อง (Local Database) ด้วยไฟล์รูปแบบ `.csv` 

โปรเจกต์นี้พัฒนาขึ้นเพื่อฝึกฝนและแสดงทักษะด้าน **File Handling**, **String Manipulation**, และการทำ **Data Cleaning** โดยไม่พึ่งพาไลบรารีภายนอกหรือระบบ Algorithm ที่ซับซ้อน มุ่งเน้นการใช้ตรรกะ (Logic) ที่มีเสถียรภาพและทำงานได้จริง

---

## 🚀 ฟีเจอร์เด่นของโปรแกรม (Key Features)

*   **Custom String Library (`stringpro.hpp`):** พัฒนา Namespace `pro` ขึ้นมาเองเพื่อจัดการกับข้อความ เช่น การดักจับคำ (`start_with`), การตัดคำจนถึงจุดที่กำหนด (`get_str_until`, `sub_str_until`) เพื่อใช้ในการแกะข้อมูล CSV ได้อย่างแม่นยำ
*   **Automatic Data Cleaning:** มีระบบตัดช่องว่างสากล (`deleteEmpty`) ตั้งแต่เริ่มอ่านบรรทัด ป้องกันข้อผิดพลาดจากมนุษย์ (Human Error) หากเผลอกดเว้นวรรคตอนคีย์ข้อมูล
*   **Persistent Storage:** บันทึกข้อมูลลงไฟล์ `data.csv` แบบถาวร สามารถนำไปเปิดและประมวลผลต่อบน Microsoft Excel หรือ Google Sheets ได้ทันที
*   **Comment Support:** รองรับการใส่หมายเหตุหรือคอมเมนต์ในไฟล์ข้อมูล หากบรรทัดไหนขึ้นต้นด้วยจุด `.` โปรแกรมจะข้ามการทำงานไปบรรทัดถัดไปอัตโนมัติ
*   **Data Day Checking:** เช็คข้อมูลผ่าน วว/ดด/ปป ได้ Function ใหม่อัปเดต 25/10/69
*   **Data Expenses Checking:** รองรับการคำนวณรายจ่ายทั้งหมดแล้วส่งกลับมาเป็นทศนิยม อัปเดต 25/10/69
*   **Data Income Checking:** รองรับการคำนวณรายรับทั้งหมดแล้วส่งกลับมาเป็นทศนิยม อัปเดต 25/10/69
*   **Data Days Checking:** รองรับการเช็คหลายวันโดยหลักการทำงานคือกลับหัววันที่
และเช็ค YY/MM/DD แทนการเช็ค DD/MM/YY เพื่อป้องกันความผิดพลาด อัปเดต 25/10/69
*   **Data Edit:** รองรับการแก้ไขข้อมูลด้วย วันที่เดือนปีและเวลา และใส่ข้อมูลชชุดใหม่ลงไปแทนที่ อัปเดต 25/10/69
*   **Data Checking Correct:** รองรับการเช็ค Data ว่าถูกหรือไม่ นับจำนวน comma เป็นหลัก อัปเดต 26/10/69

## 🛠️ โครงสร้างซอร์สโค้ด (Code Architecture)

*   `main.cpp` : ส่วนควบคุมหลักของโปรแกรม ทำหน้าที่เรียกอ่านข้อมูลและจัดการ Flow การแสดงผล
*   `stringpro.hpp` : ไลบรารีการจัดการข้อความ (String Manipulation) ที่เขียนขึ้นเองในรูปแบบ `inline` ฟังก์ชัน

```text
Day: 25/10/69 Time: 12:00 Expenses: 100 Income: 200

Day: 25/10/69 Time: 13:00 Expenses: 0 Income: 10

Day: 25/10/69 Time: 15:00 Expenses: 0 Income: 50.10

Day: 26/10/69 Time: 12:00 Expenses: 0 Income: 0

Day: 26/10/69 Time: 13:00 Expenses: 0 Income: 10

Day: 27/10/69 Time: 12:00 Expenses: 0 Income: 0

Day: 29/10/69 Time: 12:00 Expenses: 0 Income: 0

```

## 🔧 วิธีการติดตั้งและรันโปรแกรม (How to Run)

รองรับการคอมไพล์ด้วย G++ (C++17 ขึ้นไป) โดยไม่ต้องติดตั้งไลบรารีเสริมเพิ่มเติม

1. คลอนรีโพสิทอรีนี้ไปยังเครื่องของคุณ:
   ```bash
   git clone https://github.com/overants01/csv-data-parser-cpp
   ```
2. รันโปรแกรม:
   ```bash
   ./mainMAC
   ```
   หรือ Window
   ```bash
   ./mainWindow.exe
   ```

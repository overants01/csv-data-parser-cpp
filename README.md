# cpp-expense-tracker 📊

โปรแกรมบันทึกรายรับ-รายจ่ายผ่านหน้าจอคอนโซล พัฒนาด้วยภาษา **C++17** โดยจำลองการทำงานของระบบฐานข้อมูลภายในเครื่อง (Local Database) ด้วยไฟล์รูปแบบ `.csv` 

โปรเจกต์นี้พัฒนาขึ้นเพื่อฝึกฝนและแสดงทักษะด้าน **File Handling**, **String Manipulation**, และการทำ **Data Cleaning** โดยไม่พึ่งพาไลบรารีภายนอกหรือระบบ Algorithm ที่ซับซ้อน มุ่งเน้นการใช้ตรรกะ (Logic) ที่มีเสถียรภาพและทำงานได้จริง

## 🚀 ฟีเจอร์เด่นของโปรแกรม (Key Features)

### ✨ เวอร์ชันอัปเดตใหญ่ (Major Remake - OOP & Vector Architecture) [อัปเดต 17/11/69 | 17/11/26]
*   **Object-Oriented Architecture (`Record` Class):** ปรับโครงสร้างใหม่ทั้งหมดเป็นรูปแบบ OOP โหลดข้อมูลเฉพาะวันที่ที่ต้องการเข้าสู่ `std::vector` บนหน่วยความจำ (RAM) ช่วยลดการอ่านไฟล์ซ้ำซ้อนและทำงานได้รวดเร็วขึ้น
*   **Smart Function Overloading (`get_income` & `get_expenses`):** ฟังก์ชันอัจฉริยะที่ทำงานได้ 2 รูปแบบ หากใส่เวลา (เช่น `"12:00"`) จะดึงยอดเฉพาะเวลานั้น แต่หากไม่ใส่พารามิเตอร์จะคำนวณยอดรวมทั้งหมดให้อัตโนมัติ
*   **Real-time Balance Calculation (`get_balance`):** คำนวณยอดเงินคงเหลือสุทธิ (รายรับหักลบรายจ่าย) ด้วยหลักการ DRY (Don't Repeat Yourself) แม่นยำระดับจุดทศนิยม
*   **In-Place Record Editing (`t.Edit`):** แก้ไขข้อมูลรายรับ-รายจ่ายตามช่วงเวลาที่กำหนด พร้อมอัปเดตข้อมูลทั้งในหน่วยความจำและเขียนทับลงไฟล์ `.csv` แบบถาวรทันที
*   **Clean Display Methods (`print_income` & `print_expenses`):** แยกส่วนแสดงผลออกจากส่วนคำนวณอย่างชัดเจน ช่วยให้แสดงรายงานสรุปยอดรายวันได้สะอาดตาและอ่านง่าย

### 📦 ฟีเจอร์พื้นฐานและเครื่องมือจัดการระดับไฟล์ (Core & Legacy Utilities)
*   **Custom String Library (`stringpro.hpp`):** พัฒนา Namespace `pro` ขึ้นมาเองเพื่อจัดการกับข้อความ เช่น การดักจับคำ (`start_with`), การตัดคำจนถึงจุดที่กำหนด (`get_str_until`, `sub_str_until`) เพื่อใช้ในการแกะข้อมูล CSV ได้อย่างแม่นยำ
*   **Automatic Data Cleaning:** มีระบบตัดช่องว่างสากล (`deleteEmpty`) ตั้งแต่เริ่มอ่านบรรทัด ป้องกันข้อผิดพลาดจากมนุษย์ (Human Error) หากเผลอกดเว้นวรรคตอนคีย์ข้อมูล
*   **Persistent Storage:** บันทึกข้อมูลลงไฟล์ `data.csv` แบบถาวร สามารถนำไปเปิดและประมวลผลต่อบน Microsoft Excel หรือ Google Sheets ได้ทันที
*   **Comment Support:** รองรับการใส่หมายเหตุหรือคอมเมนต์ในไฟล์ข้อมูล หากบรรทัดไหนขึ้นต้นด้วยจุด `.` โปรแกรมจะข้ามการทำงานไปบรรทัดถัดไปอัตโนมัติ
*   **Data Day Checking:** เช็คข้อมูลผ่านรูปแบบ วว/ดด/ปป ได้ *(อัปเดต 25/10/69 | 25/10/26)*
*   **Data Expenses & Income Checking:** รองรับการคำนวณรายรับและรายจ่ายทั้งหมดแล้วส่งค่ากลับมาเป็นทศนิยม *(อัปเดต 25/10/69 | 25/10/26)*
*   **Data Days Checking (ISO Date Comparison):** รองรับการค้นหาข้อมูลข้ามหลายวัน โดยปรับอัลกอริทึมให้จัดเรียงเป็น `YY/MM/DD` แทน `DD/MM/YY` เพื่อป้องกันความผิดพลาดในการเปรียบเทียบข้ามเดือนหรือข้ามปี *(อัปเดต 25/10/69 | 25/10/26 & ปรับปรุงใหม่ 17/11/69 | 17/11/26)*
*   **Data Edit (File Level):** รองรับการแก้ไขข้อมูลด้วยวันที่และเวลา พร้อมนำชุดข้อมูลใหม่ลงไปแทนที่ในไฟล์ *(อัปเดต 25/10/69 | 25/10/26)*
*   **Data Validation (`IsCorrectData`):** ระบบตรวจสอบความถูกต้องของรูปแบบข้อมูลก่อนบันทึก โดยเช็คจำนวนเครื่องหมายจุลภาค (Comma) เป็นหลัก *(อัปเดต 26/10/69 | 26/10/26)*

## 🛠️ โครงสร้างซอร์สโค้ด (Code Architecture)

*   `main.cpp` : ส่วนควบคุมหลักของโปรแกรม ทำหน้าที่เรียกอ่านข้อมูลและจัดการ Flow การแสดงผล
*   `stringpro.hpp` : ไลบรารีการจัดการข้อความ (String Manipulation) ที่เขียนขึ้นเองในรูปแบบ `inline` ฟังก์ชัน stringpro.hpp เป็นงาน AI 80% ผมเลยเอามาประยุกต์ใช้ภายใน .cpp

## 🔧 วิธีการติดตั้งและรันโปรแกรม (How to Run)

รองรับการคอมไพล์ด้วย G++ (C++17 ขึ้นไป) โดยไม่ต้องติดตั้งไลบรารีเสริมเพิ่มเติม

1. คลอนรีโพสิทอรีนี้ไปยังเครื่องของคุณ:
   ```bash
   git clone https://github.com/overants01/csv-data-parser-cpp
   ```
2. รันโปรแกรม:
   ```bash
   ./mainMAC
   ```
   หรือ Window
   ```bash
   ./mainWindow.exe
   ```
